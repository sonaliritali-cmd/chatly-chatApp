
# Chatly - Chat Application

Chatly is a WhatsApp-inspired chat application
built using HTML, CSS and JavaScript.

## Features
- Chat interface and sample conversations
- Send and reply to messages
- Create groups
- Post and view text statuses
- Voice and video call demo screens
- Call history
- Share images
- Search chats and messages
- Edit profile
- Dark mode
- Save data in browser local storage
- Responsive layout

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser.
3. For development, use the VS Code Live Server extension.

## Limitations
This is a front-end demonstration project.
Real-time messaging between users and actual
voice/video calls are not implemented.
